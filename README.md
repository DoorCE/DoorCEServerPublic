## About DoorCE

**DoorCE – Data Opener Open Data for Central Europe** is an Interreg CENTRAL EUROPE project focused on improving the availability, quality, and usability of open data across Central European regions and municipalities.

The project brings together public authorities, research institutions, technology partners, and other organisations to develop practical tools, methodologies, and knowledge supporting the publication and reuse of open data.

More information about the project, its objectives, activities, partners, and results is available on the official project website:

**[DoorCE – Interreg CENTRAL EUROPE](https://www.interreg-central.eu/projects/doorce/)**

## About this repository

### DoorCE UDAS Server

The UDAS Server component constitutes the backend layer of the UDAS (Universal Data Acquisition System) tool.
It provides several APIs for manipulation of various UDAS resources, to be used mainly by UDAS Panel and UDAS Platform.
The repository is divided into three parts. 
The DoorCEModel part contains the central data model and related database support.
The DoorCEServer part contains the main server implementation, including the API endpoints and business logic.
The DoorCEGenerator part contains the app code generator, which is used to generate application code from textual scenarios and data schemas.
